# Product Roadmap

[x] Miami-Dade Chauffeur's License Upload & Display — Add ability for drivers to upload their Miami-Dade Chauffeur's License (front only) via dashboard, store URL in database, and display license badge and viewable image in parent search results to build trust through transparent credential verification. `M`

2. [x] Clickable Phone Numbers on Driver Profiles — Display driver phone numbers in search results and profile views, implement tel: links for mobile click-to-call functionality, and ensure proper formatting and accessibility for immediate communication. `XS`

3. [x] Terms of Service Acceptance During Signup — Create a basic placeholder Terms of Service document, add mandatory TOS checkbox to both driver and parent registration flows, store acceptance timestamp in database, and prevent account creation without agreement. `S`

4. [x] English/Spanish Translation Toggle — Implement internationalization (i18n) framework, create translation files for all UI text across dashboard pages and main landing page, add language toggle button in navigation bar, and persist language preference in user session or local storage. `L`
